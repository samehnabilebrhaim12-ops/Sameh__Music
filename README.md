## 🚀 كيفية رفع الموقع على GitHub ونشره مجاناً للجميع (GitHub Pages)

لتجعل موقعك يعمل على الإنترنت ويظهر لأي شخص في العالم مجاناً، اتبع الخطوات البسيطة التالية:

### الخطوة 1: إنشاء مستودع جديد (Repository) على GitHub
1. افتح حسابك على [GitHub.com](https://github.com).
2. اضغط على زر **"+"** في الأعلى واختر **New repository**.
3. اكتب اسم المستودع (مثلاً: `sameh-nabil-songs` أو `songs`).
4. تأكد من تحديد المستودع كـ **Public** (عام).
5. اضغط على **Create repository**.

### الخطوة 2: رفع ملفات الموقع
1. داخل صفحة المستودع الجديد على GitHub، اضغط على **uploading an existing file**.
2. قم بسحب وإسقاط **جميع الملفات والمجلدات** الم وجودة داخل مجلد الموقع:
   - `index.html`
   - مجلد `css/`
   - مجلد `js/`
   - مجلد `assets/`
   - ملف `README.md`
3. في أسفل الصفحة اضغط على زر **Commit changes**.

### الخطوة 3: تفعيل GitHub Pages (نشر الموقع مجاناً)
1. من قوارم المستودع على GitHub، اضغط على **Settings** (الإعدادات).
2. من القائمة الجانبية اليسرى، اضغط على **Pages**.
3. تحت قسم **Build and deployment** -> **Branch**:
   - اختر فرع `main` (أو `master`).
   - اختر مجلد `/ (root)`.
   - اضغط على زر **Save**.
4. انتظر دقيقة واحدة، وقم بتحديث الصفحة، ستظهر لك رسالة باللون الأخضر مع رابط موقعك المباشر:
   `https://YOUR_USERNAME.github.io/sameh-nabil-songs/`

## 🎶 كيفية إضافة أغاني وعيّنات جديدة في المستقبل

إذا أردت إضافة أغاني جديدة بصوتك إلى المشغل في الموقع:
1. ضع ملف الأغنية الـ MP3 في مجلد `assets/songs/` (مثال: `song1.mp3`).
2. افتح ملف `js/songs-data.js`.
3. اضف أغنيتك الجديدة في القائمة بالشكل التالي:

```javascript
{
  id: 7,
  title: "أغنية عيد ميلاد باسم (أحمد)",
  recipient: "أحمد",
  category: "birthdays",
  categoryName: "أعياد الميلاد",
  duration: "03:10",
  cover: "assets/images/song_cover.jpg",
  audioUrl: "assets/songs/song1.mp3",
  description: "أغنية حماسية ومبهجة بمناسبة عيد الميلاد."
}
```
